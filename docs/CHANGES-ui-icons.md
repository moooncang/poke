# 도트 인터페이스 1차 — Codex · 2026-10-12

기준: main `dabdc2e`. Claude의 `DESIGN-BRIEF-icons-ui.md`와 `DESIGN-HANDOFF.md` 3부를 읽고, 지침의 1~3순위를 중심으로 적용했습니다.

## 적용

- 직접 제작한 도트 아이콘 53종, 16/24/32px 투명 PNG 159장. `PixelIcon`과 `icon()`으로 공통 접근하며 인접 텍스트와 수치를 유지합니다.
- HUD: 능력치 아이콘·두꺼운 막대, 소지금 옆 볼 개수, 명성/악명·상태 아이콘, 선두 왕관·고정/전설 표시, 볼 형태 파티 슬롯. 변화량은 1.5초 강조하며 돈에 P 단위를 붙입니다.
- 선택창: 키캡 번호, 성공률 게이지, 성공/실패 구분, 아이콘 효과 칩, 대출·복역·동료 상실 표시. 악명/빚 증가는 손해 색, 감소는 이득 색으로 표시합니다. 확률 계산은 그대로입니다.
- 기록: 사건 종류 도트, 나이별 구분선, 주요 사건·특별한 만남의 금색 띠. 일상은 조금 더 조밀하게 표시합니다.
- 인물 카드: 트레이너 사진 프레임, 직업/목표 아이콘, 명성/악명 막대, 수배·복역·빚 상태에 맞는 색과 패턴.
- 파티 관리: 타입 이름 칩, 리본 수, 친밀도 막대. 기존 편성 핸들러 유지.
- 모바일: 기존 6개 메뉴 모두 유지한 하단 탭, 짧은 라벨, 챕터 장식 축소, 전체 높이 선택 시트. 탭 접근성 이름은 원래 이름입니다.
- 새 변화량 애니메이션은 동작 줄이기 또는 16배속에서 끕니다.

## 파일 / 경계

새 에셋 `public/assets/icons/`, 제작 스크립트 `scripts/build_ui_icons.py`(개발 시 Pillow 필요, 앱 의존성 없음). 스타일은 `life.css` 끝의 `Codex · original pixel interface` 블록. `App.jsx` 변경은 나이 구분선·메뉴 표현·data-speed만입니다. 엔진·데이터·확률·저장 키·진행 간격은 변경하지 않았습니다.

다음 디자인 단계는 별도 작업: 지방 배지 72종과 배지 케이스, 리본/심볼 전체 세트, 엔딩 카드 뒤집기·메달 토스트·장면 타일. 모바일 HUD 스크롤 접힘과 모든 기존 애니메이션의 16배속 통합 제어도 아직 구현하지 않았습니다. 이번에는 새 변화량 애니메이션만 제어합니다.
