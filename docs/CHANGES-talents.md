# Codex — 5단계 타고난 재능

기준 커밋 e334f28. 교배·모험·엔딩 및 기존 선택 간격을 유지합니다.

## 배정과 밸런스

- 각 삶에는 배틀 감각 / 탐구 지능 / 포켓몬 교감 / 제작·경영 감각 중 한 분야와 1–5단계가 배정됩니다.
- 단계: **기초형 · 보통 · 유망주 · 수재 · 천재**. 배정 구간은 12% / 43% / 28% / 14% / 3%입니다. 분야는 4개 중 균등 배정합니다.
- 시드의 별도 해시로 결정해 기존 시뮬레이션 RNG를 소비하지 않습니다. 출신·성별·재산과 독립입니다.
- 관련 판정 가산: +0 / +2 / +5 / +8 / +12%p. 스탯·난이도 계산 후 더하며 최종 성공률은 계속 5–95%입니다. 확정 선택에는 적용하지 않습니다.
- `challenge.talent`가 명시된 도전에서 분야가 일치할 때만 적용합니다. 명문 아카데미, 학습/배틀/연구/돌봄/업무 판정 사건, 직업 평가, 교배 및 새 재능 사건에 연결했습니다. 실제 배틀 승패를 직접 보정하지 않습니다.
- 관련 직업(트레이너/연구원/돌보미/상인)에 종사할 때 연간 파티 경험치에 +0 / +3 / +6 / +10 / +15%를 적용합니다. 다른 직업이나 은퇴 후에는 적용하지 않습니다. 기존 건강·나이·학습 보정은 유지합니다.

## 사건과 분기

- 4분야 × 5단계 = **20개 전용 사건**, 후속 지도 선택과 지역 활동 소식 **2개 여파**. 메인 사건 풀은 802 → **822개**입니다.
- 7·12·18·22세 학습 결정과 공간이 있는 진로 평가에 재능별 선택을 추가합니다. 기존 진학·비진학·취업·자율 활동 선택은 유지합니다.
- 1–2단계는 맞춤 기초 멘토링, 3단계는 유망주 실습, 4–5단계는 판정이 필요한 특별 추천 과정입니다. 다른 관심사를 선택할 수 있습니다.
- 전용 사건에서 경쟁/평가, 지역 봉사, 다른 분야 탐색으로 분기합니다. 기초형에게는 반복 관찰·기초 돌봄 같은 이야기가, 천재에게는 학회 검증·챔피언 코치·리그 장비 개발 초청 같은 이야기가 열립니다.
- 후속 지도에서 검증 도전, 동료와 기초 과정 수료, 중단 중 선택합니다. 수료는 해당 분야 숙련 +3%p를 한 번만 부여하며 타고난 단계 자체는 바꾸지 않습니다. 평가 실패 시 3–5년 뒤 재평가를 받을 수 있습니다.
- 새 긴급 사건을 만들지 않아 선택 사이 4–7개 자동 기록 규칙은 그대로입니다.

## 저장·UI·협업

- **저장 버전 3**. 새 필드 `talent: { field, level }`. v1 → v2 → v3 순서로 이전하며 v2의 기록·진행 중 선택·RNG는 변경하지 않습니다. 이전 삶의 시드로 재능만 배정합니다.
- 이미 열린 구형 선택에는 `challenge.talent`를 소급 삽입하지 않습니다. 기존 결과 기록도 재계산하지 않습니다. 3버전의 누락/잘못된 재능 필드 및 알 수 없는 challenge.talent는 거부합니다.
- 저장 키 `pokelife.story.v1`은 유지합니다.
- 출생 화면, 트레이너 재능 패널, 선택의 판정 설명, 엔딩에 재능 표시. 성장 보정은 기존 연간 육성 수치에 반영됩니다.
- 핵심: `sim/talent.js`, `data/talent-events.js`. 기존 모듈의 import 순환을 피하도록 재능 계산은 독립 모듈에 둡니다. 새 도전은 `challenge.talent`에 battle/research/care/craft를 명시하세요.
