## 1. 더 많은 사건이 실제로 보이게 — "스스로 정한 일"

한 삶의 플레이어 결정은 약 70번뿐이라, 사건을 늘려도 대부분은 한 번도 보이지 않았습니다. 결정 사이의 자동 기록 중 30%(`AUTO_SHARE`)를 **캐릭터가 혼자 처리하는 작은 사건**으로 바꿨습니다.

- **처리 방식:** `engine.js`의 `nextFiller` → `directEvent(s, { auto: true })`로 사건을 고르고, `pickChoice`(자동 결정과 같은 성향·목표·성공률 가중치)로 바로 해결합니다. 선택창은 뜨지 않습니다.
- **열리는 분류:** `AUTO_CATEGORIES`(`local`, `pokemon`, `stage`, `family`, `opportunity`, `work`, `childhood`) 중 긴급하지 않은 사건만. 인연(`cast`)·세계(`world`)·리그·전설·지방 이야기처럼 관계나 큰 결정을 바꾸는 사건은 계속 플레이어가 고릅니다.
- **기록:** 항목에 `auto: true`, `kind: 'auto'`가 붙고 `resolution`이 바로 채워집니다. 화면에는 "스스로 정한 일"로 표시됩니다.
- **간격 규칙은 그대로입니다.** 선택 간격 계산(`recordsSinceDecision`, `recordGap`)은 `auto` 항목을 결정으로 세지 않습니다. `advance` 한 번에 기록 한 줄도 그대로입니다.
- **결과:** 자동 결정 표본에서 한 삶에 스스로 정한 일이 약 50~65개. 8명 표본에서 서로 다른 사건 출처가 429 → 615로 늘었습니다.

**밸런스 조정**
- 필드 분류 가중치 1.4 → 1.2.
- 야생 조우 우선 배정을 "3년 → 4년 동안 조우 없음"으로 바꿨습니다.
- 결정 중 필드 사건 비중은 32% → 25%.

## 3. 콘테스트와 배틀 시설

**콘테스트** (`sim/contest.js`, `data/contests.js`, 새 선택지 필드 `contest: { category, rank }`)
- **부문과 랭크:** 멋짐·아름다움·귀여움·슬기로움·강인함 5부문 × 노말·슈퍼·하이퍼·마스터 4랭크.
- **출전과 점수:** 부문에 가장 잘 맞는 파티 포켓몬이 나갑니다. 점수는 타입 적합 25 + 친밀도×0.25 + 레벨×0.3 + (행복+유대)/10 + 운 0~15. 경쟁자는 `35 + 랭크×13 + 0~20`.
- **우승 보상:** 플래그 `ribbon-<부문>-<랭크>`가 세워지고, 개체 `ribbons`에 리본이 추가됩니다. 상금은 200~1,200P이고 명성도 오릅니다.
- **회장:** 호연·신오에는 콘테스트 회장이, 칼로스에는 쇼케이스가 있습니다. 다른 지방에서는 순회 콘테스트(노말·슈퍼)가 열립니다.
- **이어지는 이야기:** 라이벌 코디네이터, 리본 케이스, 그랜드 페스티벌(마스터 리본 3개), 심사위원 제안.
- **시뮬레이션 우승률:** 강한 귀여움 파트너 기준 노말·슈퍼 거의 100%, 하이퍼 약 50%, 마스터는 매우 어려움.

**배틀 시설** (`data/frontier.js`, 새 배틀 종류 `facility`)
- **호연 배틀프런티어 7개 시설:** 타워·돔·팰리스·아레나·팩토리·파이크·피라미드.
  - 프런티어 패스(배지 8개 또는 명성 30, 또는 '배틀 시설 정복' 목표)가 있어야 열립니다.
  - 심볼은 실버(Lv.42→54) → 골드(Lv.58→72) 순서입니다.
  - 팰리스·아레나·팩토리·파이크·피라미드는 시설 규칙 판정(유대·용기·지식·건강)에 성공해야 연전이 시작됩니다.
- **다른 지방 시설 8곳:** 트레이너 타워, 성도·신오·가라르 배틀타워, 배틀서브웨이, 배틀메종, 배틀트리, 아카데미 에이스 토너먼트. 각각 연승 기록 3단계(`facility-<id>-1..3`)입니다.
- **배틀 규칙:** `facility` 연전 상금은 마지막 승리에서 한 번만 지급합니다. `battle.opponents`는 league·gym·facility에서만 허용됩니다.
- **목표:** '콘테스트 스타'(contest ×4)와 '배틀 시설 정복'(frontier ×4, 육성 +15%)을 추가했습니다.
