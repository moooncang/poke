최신 main을 먼저 반영한 뒤 `src/ui/`로 분리된 컴포넌트 위에서 작업했습니다. 이전 `src/LifeView.jsx`, `src/components.jsx`, `src/game.js`를 복원하지 않았습니다.

## 변경한 화면

- 짙은 청록색 배경·패널, 민트색 진행 버튼, 분홍색 트레이너 라이선스와 선택창 헤더를 적용했습니다. 기존 포켓몬 도트, 초록색 파티 카드와 작은 마을 장면을 함께 사용합니다.
- 데스크톱 1200px 이상: 왼쪽 트레이너/능력치/인연, 가운데 사건 기록, 오른쪽 파티/지방 정세/장비의 3열입니다.
- 801–1199px: 가운데 콘텐츠와 오른쪽 정보 패널의 2열입니다. 800px 이하에서는 기록을 먼저 보여 주고 정보 패널이 뒤에 이어집니다. 520px 이하에서는 패널도 한 열입니다.
- 프로필에 성별에 맞는 기존 트레이너 스프라이트를 표시합니다. 파티에는 다음 레벨 경험치 막대와 남은 슬롯을 추가했습니다. PC 박스의 기존 열람 동작을 유지합니다.
- 결정 팝업, 판정 결과, 도감, 세계 지도, 출생/설정 팝업, 숨긴 선택창의 배속 바까지 어두운 테마에 맞췄습니다. 선택지 hover와 키보드 focus 색을 구분합니다.
- 장면 높이는 데스크톱 132px, 모바일 116px로 제한해 사건 기록이 아래로 밀리지 않게 했습니다.

## 수정 파일과 이어서 작업할 때

| 파일 | 변경 |
|---|---|
| `src/App.jsx` | `LifeSidebar`를 `side="trainer"`와 `side="world"`로 나눠 중앙 main 양쪽에 배치 |
| `src/ui/LifeView.jsx` | 사이드바 그룹 분리, 트레이너 초상, 파티 경험치와 빈 슬롯 |
| `src/life.css` | 마지막 `Codex UI refresh` 주석부터 테마·반응형 규칙 추가 |

CSS 로딩 순서는 기존 `styles.css → game.css → life.css`입니다. 새 테마는 `life.css` 끝의 `--ui-*` 변수와 규칙을 사용합니다. 이전 밝은 색 선언을 다시 우선시키지 않도록 주의해 주세요. `LifeSidebar`의 기본 `side` 값은 `trainer`이고, 전체 정보를 표시하려면 두 그룹 모두 렌더링해야 합니다.

선택창 숨기기/복원, inert와 포커스 처리, 자동 진행, 배속, 저장 형식 2, 세계·인연·여파·자동 파티 구성에는 기능 변경이 없습니다. 시뮬레이션 데이터와 규칙도 수정하지 않았습니다.
