# 디자인 향상 지침 — UI와 도트 아이콘 (GPT용)

작성: Claude · 2026-10-12 · 기준 `c8ebf02`
대상: GPT(디자인 담당). 이 문서는 **지침만** 담습니다. 만들어진 아이콘이나 CSS는 없습니다. 구조·클래스·데이터 상태는 [DESIGN-HANDOFF.md](DESIGN-HANDOFF.md) 1~3부가 기준이고, 이 문서는 그 위에 "플레이어가 좋아할 모습"을 정합니다.

## 0. 한 문장 목표

**"포켓몬 게임기 화면을 들여다보는 기분"** — 글자 목록이 아니라 도트 아이콘·몬스터볼·배지·리본이 눈에 먼저 들어오고, 숫자는 그 다음에 읽히는 화면.

## 1. 지금 화면의 문제 (플레이어 눈으로)

1. 모든 정보가 **글자**다. 배지 11개, 챔피언 0, 리본 3 — 전부 텍스트. 포켓몬 게임은 배지 케이스를 "본다".
2. 아이콘이 lucide(선 아이콘)라 도트 스프라이트와 **질감이 안 맞는다**. 포켓몬 도트 옆에 얇은 선 아이콘이 있으면 웹앱처럼 보인다.
3. 상태 변화가 **소리 없이** 지나간다. 돈이 300P 줄어도, 악명이 10 올라도, 숫자만 바뀐다.
4. 결정창에서 선택지의 **결과가 읽기 어렵다**. "유대 +3 · 소지금 −100P"가 작은 회색 글자다.
5. 사건 기록이 길어질수록 **모두 똑같이 생겼다**. 중요한 사건(체포·결혼·챔피언)과 일상 기록이 같은 카드다.
6. 모바일에서 **첫 화면에 보이는 것이 적다**. 헤더 + 빵부스러기 + 탭 + HUD까지 내려와야 사건이 보인다.

## 2. 도트 아이콘 — 만들 목록

### 규격
- **16×16 기본, 24×24·32×32 변형**(24는 HUD·탭, 32는 카드·모달 제목). 모두 1배 픽셀 아트로 그리고 CSS `image-rendering: pixelated`로 2~3배 확대. `.pixel` 클래스가 이미 있다.
- 팔레트: 아이콘당 **4~8색**, 외곽선은 진한 남색(`#1b2a35` 계열), 하이라이트 1색. 기존 스프라이트(PokéAPI 도트)와 같은 톤이어야 한다. 어두운 배경(`--ui-panel`)에서도 읽히게 **밝은 외곽선 변형**은 만들지 말고, 아이콘 자체 명도를 높여라.
- 파일: `public/assets/icons/<이름>.png`(16), `<이름>@24.png`, `<이름>@32.png`. 투명 배경. 이름은 아래 표의 id.
- 코드에서 쓰는 법: `asset('assets/icons/badge-kanto.png')`(`src/ui/assets.js`). 새 헬퍼 `icon(id, size)`를 `assets.js`에 추가해도 된다.
- lucide는 **기능 버튼(닫기·설정·재생·다운로드)에만** 남기고, 게임 세계의 개념(배지·리본·돈·포켓몬·악명·빚·감옥)은 전부 도트로 바꾼다.

### 그리는 규칙
- 한 묶음은 같은 각도·같은 선 굵기. 섞어 그리면 바로 티가 난다.
- 16px에서 **2픽셀 이하 디테일은 지워라**. 확대해서 예쁜 게 아니라 작게 봐서 읽혀야 한다.
- 원작 그래픽을 **복제하지 말 것**. 배지·심볼·리본은 "비슷한 분위기의 창작"이어야 한다. 몬스터볼·알은 일반 도형이라 괜찮다.
- 흑백 실루엣 변형은 CSS `filter: grayscale(1) brightness(.5)`로 만들 수 있으니 따로 그리지 않는다.

## 3. 화면별 향상 — 플레이어 입장

### 3.1 HUD (게임 화면 상단)
- **능력치 5칸은 아이콘 + 색 막대 + 숫자**, 라벨 글자는 툴팁/aria로. 막대 폭은 지금보다 2배.
- **변화량 배지(`.hud-delta`)는 결정 직후 1.5초 동안 커졌다 줄어드는 연출**(동작 줄이기 설정이면 색만). 플러스는 민트, 마이너스는 로즈, 악명은 보라. 돈은 "−300P" 같이 단위 포함.
- 소지금 옆 **몬스터볼 개수**(`life.game.balls`)를 작은 볼 아이콘 + 숫자로. 지금은 사이드바 깊숙이 있다.
- 상태 배지(`.hud-badge`)는 아이콘 + 짧은 글자. "수배 중"은 깜박이는 전단, "복역 중 · 3년 남음"은 창살 + 남은 해.
- "다음 선택까지" 버튼은 **재생 컨트롤 옆**으로 옮기는 것도 좋다(지금은 상태 줄 끝).

### 3.2 결정창 (가장 중요한 화면)
- 선택지마다 **결과 미리보기를 칩으로**: 아이콘 + 수치(`+3`, `−100P`), 좋은 건 민트 칩, 나쁜 건 로즈 칩, 판정은 "성공률 64%" 게이지 칩. `EffectChips`가 이미 있으니 아이콘만 더하면 된다.
- 판정 선택지는 **성공/실패 두 줄**을 접지 말고 보여라. 실패 쪽은 흐리게.
- **대가가 있는 선택지**(악명·빚·동료 상실·징역)는 칩에 경고색과 작은 아이콘(해골/봉투/빈 볼/창살). 플레이어가 "이건 어두운 길"임을 보고 고르게.
- 선택지 번호(`.decision-number`)에 **단축키 힌트**(키캡 모양) — 1~8.
- 성향 태그(`.choice-tags em`)는 5색 작은 도장으로.

### 3.3 사건 기록 (타임라인)
- `.timeline-dot`을 **사건 종류 도트 아이콘**으로. 색도 종류별로.
- **중요 사건은 다른 카드**: `kind-milestone`(체포·출소·파산·결혼·은퇴), 챔피언·전설 조우는 넓은 띠 + 아이콘 + 배경 패턴. 일상 기록(`kind-life`, `kind-auto`)은 좁고 옅게, 한 줄로 접혀 있다가 눌러서 펼침.
- **같은 해의 기록을 묶는 연도 구분선**("32세 · 봄") — 지금은 카드마다 나이가 반복된다.
- 결과문(`.choice-result`) 앞에 선택한 번호와 성향 도장. 판정 성공/실패는 "성공 · 64%" 스탬프.
- 배틀 결과문은 **상대 포켓몬 도트 + 내 선두 도트**를 작게 나란히(텍스트에 `{poke:id}` 토큰이 있으니 `formatText` 전에 id를 뽑아 쓰면 된다).

### 3.4 인물 카드 (사이드바)
- 트레이너 카드 모양으로: 초상 + 직업 아이콘 + 등급 별 칩 + 지방 깃발(지방색 `REGIONS[].color`). 
- "세상의 평가"는 **명성 막대와 악명 막대를 한 줄에 양쪽으로**(가운데 0, 왼쪽 악명 로즈, 오른쪽 명성 민트).
- 상태(`.cc-condition`)는 아이콘 칩. `data-mood`별 카드 테두리: 조직=로즈, 수배=깜박이는 로즈, 복역=회색 창살 패턴, 빚=금색 점선.

### 3.5 파티·포켓몬
- 파티 슬롯(`.hud-slot`)은 **몬스터볼 안에 도트**, 선두는 왕관, 고정은 핀, 전설은 자물쇠 — 전부 도트 아이콘으로.
- 파티 관리 카드에 **타입 칩 2개**와 리본 수(리본 아이콘 + n). 친밀도는 하트 막대.
- 포켓몬 상세(도감 모달)에 **동료 이야기**(만난 마을·배틀·진화·리본)를 리포트에서 가져와 붙이면 좋다(`memberStory(life, uid)` 호출만 하면 된다).
- 떠난 동료 기록(`'떠난 동료'`)은 **빈 몬스터볼** 아이콘.

### 3.6 엔딩·전당
- 엔딩 카드 뒷면/앞면 넘기기(클릭으로 뒤집기), 레어도별 테두리 반짝임(에픽 보라, 레전드 금). 카드 모서리에 `card-rarity-*` 장식.
- 트레이너 카드 별 5개는 `star-on/off` 도트. 카드 색 등급(`data-color`)은 실제 카드 배경 그라데이션으로.
- 배지 케이스: 9지방 × 8칸 격자, 딴 배지만 컬러. 리본표도 같은 방식.
- 메달 획득 순간 **토스트**(아이콘 + "메달 획득: 첫 리본"). 메달은 `medalsOf(life)`를 결정 전후로 비교하면 새로 얻은 id를 알 수 있다(App에 스냅샷 로직이 있으니 거기 붙이면 됨).
- 가계도는 **알 → 포켓몬 도트 → 이름** 체인으로.

### 3.7 모바일
- 첫 화면: 헤더 한 줄(로고 + 설정) → HUD 2줄(이름/돈/상태, 능력치 5칸) → **바로 사건 카드**. 빵부스러기·"TRAINER LOG" 도장·챕터 헤더는 접거나 지운다.
- 탭은 하단 고정 바(아이콘 5개: 게임·도감·리포트·전당·기록). 아이콘은 도트 24px.
- 결정창은 전체 화면 시트, 선택지 버튼 높이 최소 56px, 효과 칩은 줄바꿈 허용.
- HUD는 스크롤 시 **이름·돈·상태 한 줄만 남기고 접히는 sticky**.

### 3.8 장면(`LifeScene`)
- 지금은 글자(⌂ ✚ ☁)로 그린 마을이다. **환경별 배경 타일**(숲·바다·강·도시·산 5장, 320×96 도트)과 계절·날씨 레이어(낙엽·눈·비 입자), 밤낮(나이가 아니라 계절로). 트레이너+선두 포켓몬이 걷는 것은 유지.
- 지방을 옮기면 배경이 바뀌고, 복역 중이면 창살 레이어, 조직원이면 밤 배경.

## 4. 색·톤 규칙
- 기존 토큰 유지: `--ui-bg --ui-panel --ui-raised --ui-line --ui-text --ui-muted --ui-mint --ui-rose`, 금색 `#f1cf7c`. 새 토큰은 `:root`에 추가하고 이름을 `--ui-*`로.
- 의미색 고정: **좋음=민트, 나쁨=로즈, 돈=금, 악명=보라(`#b48be0`)**, 빚=주황(`#f0a35a`), 복역=회색. 능력치 5색은 HUD에 이미 있는 5색을 그대로.
- 글자 대비 4.5:1 이상. 작은 글자(11px 이하)는 `--ui-muted`보다 밝게.

## 5. 움직임
- 결정 직후: 효과 칩이 HUD로 **날아가는** 연출 1개면 충분하다(0.6초). 과하면 지친다.
- 배틀 결과: 승리 시 선두 도트가 한 번 튀어 오름, 패배 시 흔들림.
- `prefers-reduced-motion`이면 모두 끄고 색 변화만.
- 16배속에서는 모든 애니메이션 끔(`.app-shell[data-speed="16"]` 같은 속성을 App에 추가해도 됨 — 상태 추가는 UI 한정이라 괜찮다).

## 6. 하지 말 것
- 엔진 함수·저장 키·확률·문구 데이터 수정(1~3부의 "바꾸면 안 되는 것").
- 원작 배지·리본·캐릭터 그래픽 복제. 커뮤니티 스프라이트도 라이선스 확인 없이 추가 금지.
- lucide와 도트를 같은 줄에 섞기.
- 16MB 넘는 에셋 폴더, 1장에 100KB 넘는 PNG(도트는 몇 KB여야 정상).
- 정보 제거: 숫자를 아이콘으로 **대체**하지 말고 **앞에 붙여라**. 툴팁·aria-label로 라벨은 남긴다.

## 7. 작업 순서 제안
1. 아이콘 1순위 40장 + `icon()` 헬퍼 + HUD·결정창 적용 (가장 체감 큼)
2. 사건 카드 종류별 디자인 + 연도 구분선 + 중요 사건 띠
3. 인물 카드·파티 슬롯·상태 배지
4. 모바일 하단 탭·접히는 HUD
5. 배지 케이스·리본표·심볼(2순위 아이콘)
6. 엔딩 카드 뒤집기·메달 토스트·가계도
7. 장면 배경 타일

# 9. 2차 개선안 — 1차 도트 적용(`4be29c4`) 이후

1차로 아이콘과 칩이 들어왔지만, 플레이어 눈에는 아직 "정보가 많은 관리 화면"입니다. 원인은 아이콘이 아니라 **위계·여백·글자 크기·밀도**입니다. 아래는 그 다음 단계입니다. 번호는 우선순위입니다.

## 9.1 위계: 화면마다 "주인공"을 하나만
- 게임 화면의 주인공은 **지금 벌어지는 사건 카드 한 장**입니다. HUD·사이드바·탭은 조연입니다. 최신 사건 카드는 폭을 넓히고 제목 22px 이상, 본문 15px, 줄간격 1.8; 그 아래 과거 카드는 작고 옅게(제목 15px, 본문 13px, 투명도 85%).
- 결정창의 주인공은 **선택지 버튼**입니다. 상황 설명은 접을 수 있게 하고(처음엔 3줄까지만), 선택지는 세로로 크게, 각 선택지의 첫 줄(라벨)만 굵게, 효과 칩은 라벨 아래 한 줄.
- 사이드바 패널은 **접힌 상태가 기본**(인물 카드·파티만 펼침). 지방 정세·리그·키우미집·장비는 `details`로 접고, 바뀐 것이 있을 때만 점(●)으로 표시.

## 9.2 밀도: 글자 수를 절반으로
- 패널 아래 설명문(`small` "6마리를 넘으면 성향에 따라…", "16세 이후 조건에 맞으면…")은 **툴팁(ⓘ)으로 숨김**. 화면에 규칙 설명이 상주하지 않게.
- 숫자 뒤 단위·라벨 반복 제거: "명성 74 · 악명 12"는 아이콘 + 숫자만. "경력 3단계 · 12년차 · 만족 60"은 "3단계 · 12년 · 😊60"처럼 아이콘화.
- 빵부스러기("트레이너 시스템 › 하루의 플레이 기록"), "LIFE № …", "TRAINER LOG" 도장, 푸터의 긴 영문 — 데스크톱에서만 남기고 모바일에서는 제거.
- 챕터 헤더(`.chapter-header`)와 재생 바(`.playback`)를 **한 줄로 합치기**: "전성기 · 35세 · 가을 · 태초마을 | ▶ 1× 2× 3× | 자동 결정".

## 9.3 타이포·간격 시스템
- 글자 크기는 4단계만: 22 / 15 / 13 / 11px. 그 밖의 크기(8·9·10px)는 모두 11로 올립니다(지금 8~10px이 30곳 넘게 있어 모바일에서 읽기 어렵습니다).
- 간격은 4px 배수(4·8·12·16·24)만. 패널 안쪽 16, 패널 사이 12, 카드 사이 8.
- 한글 본문은 `word-break: keep-all`, 줄간격 1.7 이상.
- 모든 `meter`/`progress`는 같은 높이(8px)·같은 둥글기. 지금은 패널마다 다릅니다.

## 9.4 색: 의미색은 4개만, 장식색은 0개
- 민트(좋음·진행), 로즈(나쁨·위험), 금(돈·보상·레전드), 보라(악명·에픽). 그 밖의 색(파랑 `#6aa5d8` 등)은 그래프 선에서만.
- 패널 배경은 두 단계만(`--ui-panel`, `--ui-raised`). 카드마다 다른 그라데이션·그림자는 제거. "분홍 라이선스 헤더"처럼 한 패널만 튀는 색은 전체 톤을 깹니다 → 동일한 머리말 스타일로.
- 텍스트 대비: `--ui-muted`(#9bb5bd)를 11px에 쓰지 말 것. 11px에는 `#c3d3d8` 이상.

## 9.5 사건 카드 문법 통일
- 모든 카드는 같은 뼈대: [종류 아이콘 + 종류명 + 나이·장소] / [제목] / [본문] / [결과 블록] / [효과 칩 한 줄]. 지금은 선택·여파·특별한 만남 카드가 각각 다른 구조입니다.
- 결과 블록은 "내가 고른 것 → 일어난 일 → 바뀐 것" 세 줄 고정. 판정은 라벨 끝에 스탬프(성공 64% / 실패 64%).
- 배틀 결과문이 길다(3~5문장). 첫 문장(승패)만 보이고 나머지는 "자세히"로 접기.
- "스스로 정한 일"은 한 줄 요약 + 펼침. 펼치면 결과 블록이 보임.

## 9.6 첫 10초
- 새 사용자가 처음 보는 것은 출생 화면입니다. 출생 화면을 **트레이너 카드 발급 연출**로: 카드가 뒤집히며 이름·출신·파트너 후보·난이도·목표가 찍힘. 지금은 dl 표입니다.
- 첫 결정이 오기 전까지(6세 파트너 만남까지) 화면 상단에 짧은 안내 띠 한 줄: "6세에 첫 파트너를 만납니다 · Space로 멈춤". 그 뒤에는 사라짐.
- 빈 상태(도감 0종, 주요 기록 0개)는 도트 일러스트 한 장 + 한 문장.

## 9.7 모바일 전용
- 하단 탭은 4개만(게임·도감·리포트·전당). 여행 기록은 리포트의 섹션으로, 주요 기록은 게임 화면 필터로.
- HUD는 **1줄 요약**(이름 · 돈 · 상태 배지 · 파티 6볼)이 기본이고, 누르면 2줄째(능력치)가 펼쳐짐. 스크롤하면 1줄만 sticky.
- 결정 시트의 선택지 버튼은 화면 폭 전체, 높이 64px, 라벨 15px. 효과 칩은 2줄 허용. 시트 상단에 상황 제목만, 본문은 접힘.
- 사이드바 두 개는 모바일에서 "내 정보" / "세계" 두 탭으로 합쳐 게임 화면 하단이 아니라 **별도 시트**로.

## 9.8 체감 요소
- 레벨업·진화·배지·리본·메달·타이틀은 **토스트 한 줄 + 아이콘**(2초). 사건 카드만으로는 지나갑니다.
- 돈이 음수로 흘러 빚이 생기는 해에는 HUD 소지금이 한 번 흔들림. 체포·파산·출소·결혼·챔피언은 전체 화면 띠(1초).
- 배속 16×에서는 사건 카드가 **요약 한 줄 리스트**로 바뀜(카드 렌더링을 줄여야 끊기지 않음).

## 9.9 하지 말 것 (1차에서 보인 것)
- 아이콘 옆에 같은 뜻의 글자를 또 두지 말 것("🏅 배지 11" ← 아이콘이 '배지'를 뜻하면 "11"만).
- 한 줄에 아이콘 5개 이상 나열 금지. 묶음은 최대 4개, 나머지는 "+2".
- 패널 제목에 영문 대문자 레터스페이싱(POKÉLIFE / LIFETIME ARCHIVE 등)을 더 늘리지 말 것. 장식이 정보보다 커졌습니다.
- 애니메이션 추가 전 `prefers-reduced-motion`과 16배속 끄기를 먼저 연결할 것.

## 9.10 난이도 표시 (새로 추가된 기능)
- 새 삶의 난이도 선택(`.difficulty-picker`)은 4칸 세그먼트. 레전드는 금색 테두리 + 작은 경고문("살아남는 것 자체가 기록").
- 인물 카드의 난이도(`.cc-difficulty`)는 이름 옆 작은 칩. 보통은 표시하지 않아도 됩니다.
- 전당의 지난 삶 카드에 어려움·레전드 칩(`.legacy-difficulty`). 레전드 완주 삶은 카드 테두리를 금색으로.
