## 1. 스탯 밸런스 재확인

자동 결정 10명 표본으로 연령대별 평균을 보았더니 **행복·지혜·유대가 50대부터 90~100에 붙어** 판정 성공률이 거의 항상 95%였습니다(행복 평균 88~92, 유대 95~100). 명성만 서서히 올랐고 경력 등급은 평생 0이었습니다.

고친 것:
- **체감 수확(`diminished`).** 능력치와 명성은 70 이상에서 절반, 85 이상에서 3분의 1만 오릅니다. 손실은 그대로입니다.
- **기준값 회귀 강화.** 행복 0.1 → 0.15, 용기·지혜·유대 0.05~0.06 → 0.08. 행복의 기준값(60)은 빚 −8, 빈 지갑 −6, 복역 −15, 건강 40 미만 −6, 결혼 +3, 파티 +2로 움직입니다. 건강 기준값은 빚이 있으면 −3.
- **승급 심사(`promotion-review`).** 일하는 동안 4년마다 열리는 판정으로 경력 등급이 오릅니다(난이도 5 + 등급×6). 실패하면 만족 −5.
- **생활비 부족은 빚으로.** 예전에는 돈이 0에서 멈췄는데, 이제 모자란 만큼 빚이 됩니다.

결과(같은 표본): 행복 72~76, 지혜 60~70, 유대 65~75, 용기 46~56으로 평생 비슷한 폭을 유지하고, 판정 성공률 70%(기대 72%)로 선택이 다시 의미를 갖습니다. 경력 등급은 승급 심사에 응한 경우 약 3분의 1이 통과합니다.

## 2. 사회적 위치 — `src/sim/standing.js`

| 상태 | 저장 필드 | 규칙 |
|---|---|---|
| 악명 | `infamy` 0~100 | 효과 `{ infamy: n }`. 조직 밖에서 매년 −1. 등급: 소문이 도는(1~14) → 요주의 인물 → 악명 높은(35~59) → 수배 중(60~84) → 전설적인 무법자 |
| 빚 | `debt` | 효과 `{ debt: n }`, 선택지 `loan: n`(총 5,000P 한도), 생활비 부족분. 매년 이자 8%, 여유 돈의 30%로 자동 상환. **8,000P 이상이면 파산**: 돈 0, 박스의 포켓몬 절반 상실, 명성 −15, 행복 −12, `flags.bankrupt` |
| 복역 | `prison` 남은 해 | 선택지 `prison: n`(1~8) 또는 체포. 복역 중엔 `prison` 분류 사건만 열리고 수입·지출이 없으며 매년 행복 −3·악명 −4. 스스로 정하는 일도 없음 |
| 수배·체포 | — | 악명 60 이상이면 매년 `악명/400` 확률로 체포(형기 1~8년, 명성 −10, 조직원이면 직업 상실, `flags.arrested` 횟수) |
| 조직 | `career: 'syndicate'` | 숨은 직업(경력 평가·구인 사건에 안 나옴). 연 수입 420P, 매년 악명 +2·명성 −1. 직함: 말단 조직원 → 행동대원 → 소대장 → 간부 → 참모 → 두목. `flags['syndicate-region']`에 가입 지방 |
| 동료 상실 | `losePokemon` | `'random'·'box'·'party'`. 파트너·전설은 제외. '떠난 동료' 기록, `flags.lost` 횟수 |
| 직업 등급명 | `CAREER_RANKS` | 트레이너 신인→거장, 연구원 연구 보조→박사, 돌보미 견습→명인, 상인 점원→거상 |

체포·출소·파산은 그 해의 **주 기록(milestone)**으로 남고 기억에 저장됩니다. 분류 가중치: `misfortune` 0.8 + 돈 없음·빚·건강·치안마다 +0.4, `dark` 조직원 3.5(아니면 0.6) + 악명/60, `prison` 5.

## 4. 인물 카드와 게이머 기능

- **인물 카드**(`ui/CharacterCard.jsx`): 칭호, 직함·직업·연차·만족, 사는 곳과 거주 햇수(고향 표시), 명성·악명 등급, 배지·타이틀, 가족, 목표, 현재 상태 배지(복역·수배·조직·빚). 사이드바 맨 위. 기존 라이선스 패널은 출생 환경·성향·육성·소지금만 남겼습니다.
- **HUD**: 마지막 결정 이후 변화량 배지(능력치·소지금·명성·악명), 빚·악명 표시, 상태 배지, "다음 선택까지" 버튼(`fastForward`).
- **단축키**: 1~8 선택지, Space 진행/정지, N 기록 한 줄, F 다음 선택까지. 입력창에서는 꺼집니다.
- **저장 슬롯 3개**(설정): 슬롯 1은 자동 저장 자리(`pokelife.story.v1`), 2·3은 `.slot2`·`.slot3`. 저장·불러오기.
- **요약 복사**(설정·엔딩): 칭호·직함·파티·배지·도감·메달·시드를 텍스트로 복사(실패하면 텍스트 파일 다운로드). 함수 `ui/share.js` `shareSummary`.
- **메달 9종(그늘의 길)**, 엔딩 카드 `shadow`·`hardship`, 칭호(수배 중인 무법자, 〈조직〉의 두목, 악명 높은 트레이너), 기록실 '최고 악명', 연간 기록에 악명·빚.
