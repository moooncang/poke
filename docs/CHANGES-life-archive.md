# Codex: 포획 중복 완화 · 생애 기록관

기준: 10426a4. Claude의 v2 구조와 CSS 불러오기 순서를 유지했습니다.

## 중복 원인과 수정

마을별 5종 후보에서 현재 종 ID만 제외하던 방식은 진화 후 이전 모습이 다시 후보에 들어가고, 후보 소진 후 같은 종을 반복 포획했습니다.

- `src/sim/encounters.js`: 진화 데이터를 역으로 추적해 파티와 PC 박스의 **진화 계열**을 제외합니다. 같은 계열의 분기 진화도 제외합니다.
- 동네 → 같은 지방 → 다른 지방 서식지 순서로 새 계열을 찾습니다. 종 중복 가중치를 없애고, 최근 100개 기록에 제안된 종은 같은 탐색 범위의 다른 후보보다 후순위입니다. 관찰만 한 종은 영구 차단하지 않습니다.
- 원정은 조우 본문에 실제 서식지를 표시합니다. 거주지를 바꾸지는 않습니다. 전설은 일반 야생 후보에서 제외합니다.
- 일반 야생 후보를 모두 보유하면 관찰·서식지 관리 선택으로 바뀝니다.
- 반복 입양·알·친구 선물 및 생활 사건의 무작위 합류에도 같은 종 선택기를 적용했습니다. 이 경로는 전체 후보를 소진했을 때 중복을 허용합니다. 특정 종이 정해진 이야기 보상, 색이 다른 포켓몬, 기존 보유 개체는 유지합니다. `addPokemon` 자체는 개체의 중복을 금지하지 않습니다.
- 새 저장 필드 없음. 기존 저장에 즉시 적용되지만 이미 열린 선택지는 보존됩니다.

## 엔딩

`src/ui/Ending.jsx`에 생애 기록관을 분리하고 `modals.jsx`에서 재수출합니다. 스타일은 `life.css` 끝에 추가했습니다.

- 마지막 파티와 챔피언 타이틀을 배치한 표지, 생애 통계 6종.
- 생애 연표: 전체·선택·여파·포켓몬·인연·저장한 추억 필터, 나이 구간과 텍스트 검색. 당시 선택, 확률 판정, 결과, 효과, 여파의 원래 사건 표시. 30개씩 추가 표시하여 긴 로그 렌더링을 제한합니다.
- 동료 앨범: 박스 포함 전체 개체, 합류 나이·함께한 기간·출신·레벨·친밀도·최종 편성.
- 업적과 발자취: 9개 지방 배지/챔피언, 출생 가정과 마지막 경력, 방문 마을.
- 기록 내보내기에 선택한 문구와 판정 결과/확률 추가. 새 삶/닫기 유지.
- 기존 로그와 상태에서 계산하며 과거에 저장하지 않은 스탯/경력 이력을 만들어 내지 않습니다. 지난 직업의 구체적인 활동은 연표에서 검색할 수 있습니다.

## 검증

`tests/encounters.test.js`: 진화/박스 제외, RNG 재현, 65회 연속 새 계열, 전체 후보 소진 시 관찰 전환. 기존 파티 테스트와 전체 단위 테스트, Pages 경로 프로덕션 빌드 실행. 사용자 요청에 따라 브라우저/스크린샷 검수는 하지 않았습니다.

전체 테스트에서 드러난 기존 우선순위 문제도 수정했습니다. 가족의 사망 소식이 정기 야생 조우와 같은 긴급 풀에서 추첨되어 밀리던 문제로, `director.js`에서 이별 기록을 먼저 처리합니다.
