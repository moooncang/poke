## 바뀐 화면

- 최신 사건: 제목 22px, 본문 15px/1.8, 민트 상단선. 과거 사건은 제목 15px·본문 13px로 밀도를 낮췄습니다. 나이·계절·장소는 카드 머리말로 모았습니다.
- 자동 처리된 사건: 제목 한 줄과 펼침. 펼치기 전에는 본문 컴포넌트를 렌더링하지 않습니다. 16배속 자동 진행 중에는 다른 사건도 같은 요약을 사용합니다. 정지하거나 배속을 낮추면 일반 카드로 돌아옵니다.
- 긴 결과(140자 초과): 첫 문장과 자세히 펼침. 원문은 그대로 보존합니다.
- 결정창: 상황 설명은 기본 3줄(모바일 1줄)로 접고 선택 라벨/버튼을 크게. 성공·실패·비용 미리보기는 유지합니다.
- 사이드바: 재능·능력치·인연·정세·리그·키우미집·장비를 기본 접기. 인물 카드와 파티는 펼쳐 둡니다. 상주하던 규칙 설명은 접근 가능한 details로 옮겼습니다.
- 챕터 정보는 재생 바에 통합. 6세 미만에만 첫 파트너/Space 안내를 표시합니다.
- 주요 패널 배경은 panel/raised로 통일하고 겹친 그림자·분홍 머리말을 줄였습니다. 새 스타일의 크기는 22/15/13/11px, 간격은 4px 배수입니다.
- 모바일: HUD 기본 요약 + 능력치/목표 펼치기. 주요 하단 메뉴는 게임·도감·리포트·전당 4개입니다. 저장한 기록/여행 기록은 상단 보조 버튼으로 계속 접근할 수 있습니다. 숨긴 선택창의 복귀 바는 Claude의 기존 탭 위 배치를 보존합니다.
- 난이도: 키보드 포커스가 보이는 4칸 세그먼트, 레전드 경고, 인물/전당 칩, 레전드로 끝낸 삶 테두리.
