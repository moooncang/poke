# Codex — 교배와 108개 모험 장면 확장

기준: a8c9426. Claude v2 구조, 이전 포획 중복 완화, 엔딩 기록관을 유지합니다.

## 추가 분량

- `adventure-projects.js`: 36개 이야기 × 3단계 = **108개 선택 사건**. 제목·상황·주 행동은 장면마다 별도로 작성했습니다.
- `breeding-events.js`: 교배 시작 및 메타몽 소개 **2개 선택 사건**, 돌봄·부화·첫 성장 **3개 후속 선택**, 두 세대 사진·입양 가족 편지 **2개 자동 여파**.
- `consequences.js`: 모험 후 재회 **1개 자동 여파**. 합계 **116개 사건 정의 추가**이며, 메인 storylet 풀은 692 → **802개**입니다. 후속 여파 정의는 별도 집계합니다.

## 교배 규칙

`sim/breeding.js`가 파티와 박스에서 조합을 찾습니다. PokéAPI의 공식 알그룹과 성비를 사용하며 개체 성별은 저장된 시드·UID로 결정합니다. 신규 저장 필드가 없고 기존 저장에서도 같은 조합이 유지됩니다.

- 서로 다른 개체, 공통 알그룹, 서로 다른 암수 조합이 필요합니다. 메타몽은 무성 포켓몬과도 조합할 수 있지만 메타몽끼리는 불가능합니다.
- 미발견 알그룹(베이비 포함), 전설·환상은 제외합니다. 마나피 같은 원작의 특수 예외는 지원하지 않습니다.
- 자식은 암컷(메타몽 조합이면 다른 부모)의 진화 계열 첫 종입니다. 니드런·볼비트/네오비트는 정해진 개체 조합별 결과를 사용합니다. 지역 폼·향로·개체값·알 기술 유전은 아직 구현하지 않았습니다.
- 16세부터, 시작 제안은 6년 간격 제한. 진행 중인 교배 후속 사건이 있으면 새 제안을 막습니다. 유대 판정에 부모 친밀도와 돌보미 직업이 영향을 줍니다.
- 성공 → 1–2년 후 알 돌봄 → 1년 후 부화 → 2–3년 후 첫 성장 → 4–7년 후 두 세대 기록. 이는 인생 시뮬레이션 시간 단위이며 원작의 걸음 수와 다릅니다.
- 알을 맡거나 부화한 동료를 입양 보내는 선택이 있고 나중에 편지가 옵니다. 부화 전 거절하면 새 개체는 추가되지 않습니다.
- **교배를 선택했을 때는 같은 계열의 새 개체 합류를 허용**합니다. 일반 포획의 중복 방지와 별개입니다. 부모 종·UID는 기존 후속 사건 data에 담고 부화·성장 기록에 부모 이름이 남습니다. 개체 정보에 별도 가계도 필드는 없습니다.
- 조합이 전혀 없는 삶은 메타몽과 친해지는 사건으로 교배 기회를 얻습니다. 메타몽 보유 시 반복 제안하지 않습니다.
- 키우미집 상태를 월드 사이드바에 표시합니다. 수동 작업 버튼을 추가하지 않았고 모든 행동은 사건 선택으로 진행합니다.

## 모험 내용과 진행

9개 지방의 인물·장소 이야기 18개와 공통/직업 이야기 18개입니다. 레드·실버·난천·N·성호·윤진·코르니·AZ·릴리에·단델·페퍼, 배틀서브웨이·에리어 제로·지하대동굴·첫 파트너의 귀향·라이벌 은퇴전·세대 교체·센터 재회 등이 등장합니다. 공식 설정을 소재로 만든 팬 창작이며 원작 대사를 복제하지 않았습니다.

- 시작은 지방·직업·명성·나이·가족 조건을 확인합니다. 챔피언 자선전은 실제 지방 챔피언 플래그가 있어야 합니다.
- 성공 플래그와 최소 2년 경과가 있어야 다음 장면이 열립니다. 실패는 3년 뒤 재도전, 철회는 해당 이야기만 종료합니다.
- 새 모험은 동시에 최대 3개. 기존 사건의 4–7개 자동 기록 간격, 고정 진학·진로 사건, 배속은 그대로입니다. 긴급 사건으로 등록하지 않았습니다.
- 마지막 대결은 실제 자동 배틀과 승패를 사용합니다. 레드 Lv.75, 주요 인물 Lv.65, 고향 졸업전 Lv.35. 협력으로 마무리하는 별도 선택은 경기 승리나 리그 챔피언 칭호를 부여하지 않습니다.
- 코르니 이야기에서 메가진화, 소원의별 이야기에서 다이맥스 장비를 받을 수 있습니다. 전설 조사 결과는 도감 관측이며 임의로 포획하지 않습니다.
- 완료·종료·시점은 기존 flags/cooldowns/seeds로 저장합니다. 저장 버전 변경 없음.
