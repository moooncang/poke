## 변경 화면

- **HUD:** 트레이너 초상, 구분되는 이름·소지금, 5색 능력치 막대, 선두/전설 표시가 있는 6칸 파티 슬롯. 화면 폭 대신 메인 열 폭에 반응하는 container query를 적용했습니다. HUD 전체가 스크롤을 계속 가리지 않도록 기존 sticky를 일반 흐름으로 바꿨습니다.
- **파티 관리:** 2열 동료 카드(모바일 1열), 선택된 편성 방식, 선두·고정·전설 태그, 교체 대상 강조와 넉넉한 조작 버튼.
- **엔딩 카드:** 세로 수집 카드 형태, 희귀도별 테두리·배경, 종류별 장식 아이콘, 포켓몬 이미지와 최종 파티, 짧은 마우스 반응. 카드의 종류·희귀도·내용은 기존 계산 결과를 그대로 씁니다.
- **트레이너 카드:** 기존 별·등급 색을 활용한 라이선스 형태, 이름과 수치의 위계, 미획득 별 구분.
- **리포트:** 그래프 패널, 데이터 범례와 최신 수치, 옅은 기준선, 통계 카드, 연도 표 헤더, 동료 선택·연대기·리본/심볼 표현.
- **가문의 전당:** 누적 성적 카드, 지난 삶 상세, 메달 획득/미획득, 지방 도감 진행 막대, 가계도 연결, 후계 알 선택 상태.
- **새 삶 옵션:** 혜택과 도전 규칙의 선택/잠금 상태를 구분하는 카드.
- **사건 기록:** 스스로 정한 일은 작은 제목과 차분한 색, 플레이어 선택은 분홍색 결과 선, 후속 여파는 금색 테두리.

## 검증

사용자의 “검수는 간단하게, 실제 화면·구동은 직접 확인” 요청을 따라 인계 문서의 대량 스크린샷/브라우저 검수는 실행하지 않습니다. Pages 경로 프로덕션 빌드와 diff 검사를 실행하고, 전체 기존 테스트는 PR CI에 맡깁니다. 실제 화면을 확인했다고 주장하지 않습니다.

환경의 추적된 `node_modules` 링크가 다른 머신 경로를 가리켜 로컬 빌드는 `/tmp`의 별도 의존성을 임시 연결해 수행합니다. 해당 링크 변경은 커밋하지 않습니다.
