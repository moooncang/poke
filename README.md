# Pokélife

[플레이](https://moooncang.github.io/poke/) · 선택으로 진행하는 포켓몬 인생 시뮬레이션.

## 현재 플레이 방식

- 출생 시 9개 지방·40개 마을 중 출생지, 가족 구성·형편·주거·주변 환경을 무작위 배정합니다. 가족 형편에 따라 시작 자금과 능력치가 달라집니다.
- 삶은 자동 진행되며 사건이 나오면 팝업에서 결정합니다. 선택 후 자동으로 이어집니다. 배속은 1·2·3·4·16배, 일시 정지와 선택 자동화도 지원합니다.
- 한 번 진행할 때 한 해가 지나갑니다. 6세 첫 파트너, 7세 입학, 10세 주요 인물, 12세 중등 진학, 16세 진로, 18세 졸업 후 진학, 20세 이주, 22세 교육·견습 수료, 40세 직업 재설계, 65세 은퇴가 고정됩니다. 정규 사건이 없는 해에는 랜덤 사건을 최대 1개 배정하며, 즉시 이어지는 추가 선택은 없습니다. 기존 177개 분기 정의에 32개 생활 사건, 여행·포획·배틀·장비 사건을 추가했습니다.
- 교제, 가족 소개, 장거리, 청혼, 결혼식, 주거, 가계, 자녀 계획, 배우자의 진로·건강, 갈등과 노후 등 18단계 관계 사건이 신뢰·관계·가족 상태를 바꿉니다. 결혼하지 않거나 교제를 끝낼 수도 있습니다.
- 직접 이동·행동력·수동 배틀은 사용하지 않습니다. 지방 이동과 배틀·포획·훈련은 사건의 선택 결과로 처리됩니다. 도감과 여행 기록은 열람용입니다.
- 메가진화·Z기술·다이맥스·거다이맥스·테라스탈은 장비와 포켓몬 조건을 충족하면 자동 배틀에서 사용됩니다. 타입 상성 기반의 간소화된 팬 게임 규칙입니다.
- 기존 저장은 유지하며 새 환경 필드와 연도·관계 상태를 추가합니다. 이전 수동 배틀은 종료하고 파티를 회복한 상태로 이어집니다.
- 수명은 개인별 64–100세 한계와 60세 이후 건강에 따른 조기 사망 확률로 결정하는 창작 규칙입니다.

## 개발·배포

```sh
npm ci
npm run dev
npm test
PAGES_BASE_PATH=/poke/ npm run build
```

Node 24 사용. `main` 푸시 시 GitHub Actions에서 테스트·빌드·Pages 배포를 실행합니다. 빌드 산출물 `pokelife-dist`는 Actions에서 내려받을 수 있습니다. 브라우저 테스트는 `npm run test:browser`이며 Chromium 경로를 `CHROMIUM_PATH`로 지정할 수 있습니다. 이번 업데이트의 화면 검수는 사용자가 직접 진행합니다.

저장은 `localStorage`의 `pokelife.story.v1`을 사용합니다. 설정에서 JSON 내보내기/복원을 지원합니다. 계정 동기화는 없습니다. 새 삶으로 교체하기 전 `.previous`, 손상된 데이터는 `.recovery` 키에 보존합니다.
