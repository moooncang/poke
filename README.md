# Pokélife

[플레이](https://moooncang.github.io/poke/) · 선택으로 진행하는 포켓몬 인생 시뮬레이션.

## 현재 플레이 방식

- 플레이어 성별은 남성·여성·미지정 또는 무작위로 선택합니다. 최초 출생 화면과 게임 설정에서도 바꿀 수 있으며 프로필과 저장 데이터에 유지됩니다. 성별은 능력치나 진로 선택을 제한하지 않습니다. 기존 기록은 미지정으로 유지합니다.
- 선택창의 ‘잠깐 숨기고 화면 보기’나 닫기/Esc로 선택을 보류할 수 있습니다. 뒤의 기록·도감·지도를 확인하거나 설정을 조작한 뒤 하단 ‘선택지 다시 열기’로 돌아옵니다. 숨긴 동안에는 자동 결정이 켜져 있어도 진행하지 않습니다.
- 출생 시 9개 지방·40개 마을 중 출생지, 가족 구성·형편·주거·주변 환경을 무작위 배정합니다. 가족 형편에 따라 시작 자금과 능력치가 달라집니다.
- 삶은 자동 진행되며 사건이 나오면 팝업에서 결정합니다. 선택 후 자동으로 이어집니다. 배속은 1·2·3·4·16배, 일시 정지와 선택 자동화도 지원합니다.
- 한 해 안에서 일상 기록 여러 개가 자동으로 지나갑니다. 선택창 사이에는 선택을 요구하지 않는 기록 4~7개가 쌓이며, 직전 결정에 따라 학습·훈련·돌봄·회복·취미 기록이 이어집니다. 6세 첫 파트너, 7세 학습 방식 선택, 10세 주요 인물, 12세 성장기 활동 선택, 16세 진로, 18세 진학·견습·취업·여행·휴식 선택, 20세 이주, 22세 활동 재설계(해당 과정 선택자만 졸업·견습 수료), 40세 직업 재설계, 65세 은퇴가 고정됩니다. 학교·진학·취업은 강제하지 않으며, 학교 밖 경로에서는 졸업 사건을 표시하지 않습니다. 정규 사건이 없는 해에는 랜덤 사건을 최대 1개 배정합니다. 선택 뒤 곧바로 뜨던 공통 실행 방식 팝업은 없앴고, 전문 경로의 후속 사건은 이후 연도에 등장합니다. 선택 후 자동 진행되며 기록 대기 중 저장·복원도 지원합니다. 기존 177개 분기 정의에 32개 생활 사건, 여행·포획·배틀·장비 사건을 추가했습니다.
- 스탯 판정 사건 60종(학업·배틀·연구·구조·돌봄·공연·취업·탐사·지역·부부 활동)을 추가했습니다. 사건마다 다른 스탯을 쓰는 도전 2개와 확정 보상 선택 1개가 있습니다. 성공률은 `25 + 스탯 × 0.7 - 난이도`를 5–95%로 제한하며, 선택 전 성공률·성공/실패 결과·비용을 표시합니다. 판정에는 선택 전 스탯과 저장된 난수를 사용하므로 새로고침으로 결과가 바뀌지 않습니다.
- 18·22세에는 명문 아카데미 특별전형을 선택할 수 있고, 이후 추가 모집도 있습니다. 지혜 0/50/100에서 합격률은 10/45/80%입니다. 응시료는 합격 여부와 관계없이 200P, 합격하면 입학과 장학금 800P를 받으며 불합격하면 기존 진로를 유지합니다. 일반 진학과 비진학 경로도 그대로 선택할 수 있습니다.
- 교제, 가족 소개, 장거리, 청혼, 결혼식, 주거, 가계, 자녀 계획, 배우자의 진로·건강, 갈등과 노후 등 18단계 관계 사건이 신뢰·관계·가족 상태를 바꿉니다. 결혼하지 않거나 교제를 끝낼 수도 있습니다.
- 숨긴 선택창 하단에서도 배속을 바꿀 수 있으며 선택 후 해당 속도로 이어집니다. 생활 사건의 도전 2개와 장기 경로의 전문 평가·협업에는 성공/실패 판정이 적용됩니다. 확정 지원 보상은 20P·유대 1로 줄였습니다.
- 16세 진로 탐색, 26세 첫 경력 평가, 35세 전문 분야, 40세 전직, 50세 후배 육성, 60세 은퇴 준비를 고정합니다. 현재 직업에 따라 승급·전직·현직 유지·자율 활동 선택이 달라지고, 아카데미 이력은 연구직 전형 난이도를 낮춥니다. 경력 등급은 최대 5단계로 단계마다 연 수입이 15% 증가합니다.
- 파티의 연간 기본 경험치는 트레이너 48·연구원 28·돌보미 36·상인 18·무직 20입니다. 학업·견습·여행 및 직전 활동에 보너스가 붙고 건강 35 미만이면 60%, 65세 이후에는 70%로 조정합니다. 기록 수나 배속은 경험치에 영향을 주지 않습니다.
- 야생 조우는 계절 제한 없이 일반 사건 슬롯에서 배정합니다. 마지막 조우 후 3년 이상이면 우선 배정하며, 그 전에도 직업에 따른 추가 조우 확률이 있습니다. 고정 나이 사건과 특별 전설 관측은 우선합니다. 매년 볼 3개를 보충(최대 30개)하고, 포획·교감·분석 포획으로 동료를 늘릴 수 있습니다. 파티가 6마리면 보관함으로 자동 전송하며 사이드바에서 확인합니다.
- 직접 이동·행동력·수동 배틀은 사용하지 않습니다. 지방 이동과 배틀·포획·훈련은 사건의 선택 결과로 처리됩니다. 도감과 여행 기록은 열람용입니다.
- 메가진화·Z기술·다이맥스·거다이맥스·테라스탈은 장비와 포켓몬 조건을 충족하면 자동 배틀에서 사용됩니다. 타입 상성 기반의 간소화된 팬 게임 규칙입니다.
- 기존 저장은 유지하며 새 환경 필드와 연도·관계 상태를 추가합니다. 이전 수동 배틀은 종료하고 파티를 회복한 상태로 이어집니다.
- 수명은 개인별 64–100세 한계와 60세 이후 건강에 따른 조기 사망 확률로 결정하는 창작 규칙입니다.

## 개발·배포

```sh
npm ci
npm run dev
npm test
PAGES_BASE_PATH=/poke/ npm run build
```

Node 24 사용. `main` 푸시 시 GitHub Actions에서 테스트·빌드·Pages 배포를 실행합니다. 빌드 산출물 `pokelife-dist`는 Actions에서 내려받을 수 있습니다. 브라우저 테스트는 `npm run test:browser`이며 Chromium 경로를 `CHROMIUM_PATH`로 지정할 수 있습니다. 이번 업데이트의 화면 검수는 사용자가 직접 진행합니다.

저장은 `localStorage`의 `pokelife.story.v1`을 사용합니다. 설정에서 JSON 내보내기/복원을 지원합니다. 계정 동기화는 없습니다. 새 삶으로 교체하기 전 `.previous`, 손상된 데이터는 `.recovery` 키에 보존합니다.
