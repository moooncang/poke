# Pokélife · 어느 포켓몬 세계의 삶

포켓몬 세계에서 태어나 한 사람의 평생을 지켜보는 인생 시뮬레이션 첫 버전입니다. React 19 + Vite로 작성했고 서버나 API 키 없이 실행됩니다.

## 실행

```sh
cd /workspace/poke
npm ci
npm run dev
```

개발 서버는 5173 포트를 사용합니다. 현재 환경에서 Node 24로 검증했습니다. 배포 파일 생성은 `npm run build`, 빌드 결과의 로컬 검증은 `npm run preview`입니다. 자료와 한글 웹폰트를 로컬에서 제공하므로 플레이할 때 외부 API나 Google Fonts에 접속하지 않습니다.

## 게시된 페이지와 자동 배포

배포가 완료되면 **https://moooncang.github.io/poke/** 에서 접속할 수 있습니다. 최초 설정은 저장소의 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다. 이 설정에는 저장소의 Pages 관리 권한이 필요합니다.

`main`에 푸시하면 `.github/workflows/build.yml`이 의존성 설치, 엔진 테스트, 프로덕션 빌드 후 GitHub Pages에 게시합니다. Pull Request에서는 빌드·테스트만 실행하며 게시하지 않습니다. Actions의 **Run workflow**로 수동 실행할 수도 있습니다.

GitHub 저장소의 **Actions → Build and deploy Pokelife → 성공한 실행 → Artifacts → pokelife-dist**에서 빌드 결과물을 내려받을 수 있습니다. `dist/`는 생성물이므로 소스 커밋에는 포함하지 않고 아티팩트로 14일간 보관합니다.

게시용 빌드는 `PAGES_BASE_PATH=/poke/ npm run build`로 실행합니다. 모든 이미지·폰트·스크립트 경로에 이 접두사가 적용됩니다. 같은 경로로 로컬 검증하려면 `PAGES_BASE_PATH=/poke/ npm run preview`를 사용합니다. 기본 개발 모드는 루트 경로를 사용합니다.

## 플레이

- ‘다음 이야기’ 한 번에 한 해가 지나갑니다. 자동 진행과 1×·2×·4× 속도를 선택할 수 있습니다.
- 6살에 첫 파트너, 10살에 주요 NPC를 만납니다. 그 후 만남은 나이·지방·이전 선택·유대·이야기 씨앗에 따라 달라집니다.
- 16살에 진로, 20살에 이주, 24살에 목격담을 따를지 선택합니다. 새로운 동행, 전직, 귀향, 은퇴와 80살의 회고까지 진행됩니다.
- 자동 진행 중에도 갈림길과 특별한 만남에서는 멈춥니다. 설정에서 ‘선택도 운명에 맡기기’를 켜면 갈림길을 자동 선택합니다. 특별한 만남은 직접 닫아야 합니다.
- 전설·환상 포켓몬 목격, 색이 다른 포켓몬, 주요 NPC, 첫 파트너, 진화에 서로 다른 색·등장·입자·문구 연출을 적용했습니다. 소리를 켜면 Web Audio로 만든 짧은 화음이 함께 흐릅니다.
- 기억 속 만남은 다시 볼 수 있습니다. 책갈피를 눌러 일반 사건도 기억에 남길 수 있습니다.
- 전설 목격은 자동 포획을 뜻하지 않습니다. 색이 다른 친구와 입양한 친구는 동행에 합류할 수 있습니다.

## 첫 버전 범위

관동·호연의 12개 출생지, 트레이너·연구원·돌보미·가게 주인 4개 진로, 유년기부터 노년까지의 일상과 진로별 사건, 반복을 피하는 사건 선택, 후속 인연, 파트너의 성장, 도감·지도·인생 회고를 구현했습니다.

한 생애는 출생을 포함해 81개의 기록을 남깁니다. 콘텐츠 라이브러리에는 일상 사건 52개와 직업 사건 24개 외에 고정 전환점·만남·후속 사건·계절 사건이 있습니다. 이는 1,025종 각각에 별도의 인생 서사가 있다는 뜻은 아닙니다. 현재 만남은 12개 마을의 포켓몬 후보 및 특별한 만남 후보를 사용합니다.

출생 확률, NPC 대사·연령, 직업·관계·포켓몬 진화 시점은 팬 시뮬레이션의 창작 설정입니다. 진화는 원작 게임의 배틀·아이템 조건을 그대로 재현하지 않습니다. 마을 위치 표시와 배경 풍경도 이 UI를 위한 표현입니다. 부모·친구의 독립된 생애, 결혼·자녀, 실시간 배틀, 멀티플레이, 계정 동기화는 아직 구현하지 않았습니다.

## 저장과 복구

진행 상황은 `localStorage`의 `pokelife.story.v1`에 자동 저장합니다. 같은 브라우저에서 새로고침하면 선택·연출 대기 상태도 유지됩니다. 저장 실패는 화면에 표시합니다.

설정에서 JSON 기록을 내려받고 다시 불러올 수 있습니다. 회고에서는 읽기 쉬운 TXT 연대기도 내려받습니다. 새 삶을 시작하거나 기록을 불러오기 전에는 현재 기록을 `.previous` 키에 복구용으로 보관합니다. 손상된 저장은 `.recovery`에 보존하며 자동 실행하지 않습니다. 이 복구 키는 현재 수동 확인용이며, 기기 간 클라우드 동기화는 하지 않습니다.

이야기 씨앗·출생지·선택이 같으면 같은 진행을 재현합니다. 새 삶을 시작할 때 ‘같은 운명으로 다시 시작하기’에서 씨앗을 지정할 수 있습니다.

## 구조

- `src/engine.js`: UI와 분리한 결정적 시뮬레이션, 상태 전이, 저장 검증.
- `src/data/world.js`: 마을, 인물, 직업, 사건. 새 사건은 나이 조건·본문·효과를 추가하면 됩니다.
- `src/data/pokemon.json`: PokéAPI 원본으로부터 추린 이름·타입·도감 설명.
- `src/App.jsx`: 일기, 선택, 도감, 기억, 지도, 설정과 회고.
- `src/components.jsx`: 등장 연출, 사운드, 접근 가능한 모달, 배경 풍경.
- `public/assets/`: 로컬 이미지. 각 이미지는 실제 사용될 때 요청되며 전체 이미지를 선로딩하지 않습니다.
- `resources/`: 원본 자료, 파일별 출처·해시·권리 구분. [자료실 안내](resources/README.md), [출처 기록](resources/SOURCES.md).

## 검증

```sh
npm test
npm run test:browser
npm run build
```

엔진 테스트는 150개의 서로 다른 전체 생애를 포함해 결정성, 선택 비용, 중단, 진화 전 기억, 목격과 포획 구분, 저장·복구, 사건 중복과 상태 범위를 확인합니다.

브라우저 검증은 1440px 데스크톱과 390px 모바일에서 Chromium을 사용합니다. 기본 실행 파일은 `/usr/bin/chromium`이며 다른 환경은 `CHROMIUM_PATH`를 지정합니다. 출생·파트너, 진로 선택, 도감·지도·기억, 주요 NPC 재생, 전설 등장과 동작 줄이기, 회고 다운로드, 새 삶을 실제 UI로 확인합니다.

## 출처

Pokémon 및 관련 이미지·명칭의 권리는 각 권리자에게 있습니다. Nintendo, Creatures, GAME FREAK와 제휴하지 않은 팬 프로젝트입니다. PokéAPI 이미지 저장소의 CC0 표시와 원작 이미지 권리는 별개로 보존합니다. 일부 최신 세대 도트는 커뮤니티 제작입니다. `public/credits/`에 PokéAPI·스프라이트·Noto 폰트의 라이선스 원문을 동봉했습니다. pret의 지도·인물에 다른 도구의 오픈소스 라이선스를 적용하지 않습니다.
