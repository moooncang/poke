# Pokélife

[플레이](https://moooncang.github.io/poke/) · 포켓몬 세계를 배경으로 한 인생·탐험 시뮬레이션. React 19 + Vite, 서버 및 런타임 API 키 없이 실행합니다.

## 실행과 배포

```sh
npm ci
npm run dev
npm test
npm run test:browser
PAGES_BASE_PATH=/poke/ npm run build
PAGES_BASE_PATH=/poke/ npm run preview
```

Node 24, Chromium `/usr/bin/chromium`에서 검증합니다. 브라우저 테스트는 `CHROMIUM_PATH`로 실행 파일을 변경할 수 있습니다. 폰트·이미지·도감 데이터는 로컬 제공하며 외부 API를 호출하지 않습니다.

`main`에 푸시하면 `.github/workflows/build.yml`에서 엔진 테스트, 빌드, GitHub Pages 배포를 실행합니다. PR에서는 게시하지 않습니다. Actions에서 빌드 아티팩트 `pokelife-dist`를 14일간 내려받을 수 있습니다. Pages Source는 GitHub Actions입니다. `dist/`는 생성물로 소스 커밋에 넣지 않습니다.

## 플레이

- **진행**: 다음 해 버튼, 1·2·4·8·12·16배속. 수동 결정은 팝업에서 반드시 선택해야 진행합니다. 자동 결정을 켜면 비용을 지불할 수 있는 선택 중 하나를 고릅니다. 주요 만남은 자동 결정 여부와 관계없이 일시 정지합니다.
- **생애**: 6세 첫 파트너, 10세 지방 이동, 16세 진로, 65세 은퇴. 새 게임의 개인별 수명 한계는 64–100세이며, 60세 이후 낮은 건강이 조기 사망 확률에 영향을 줍니다. 실제 인구 통계가 아닌 게임 규칙입니다. 고정 80세 종료가 아닙니다.
- **사건**: 32개 장기 활동 경로와 양 갈래 후속 사건 96개, 27개 지방 사건 경로와 양 갈래 후속 사건 81개. 총 177개 분기 사건 정의 외에 실행 방식 추가 선택, 기존 직업·생활·주요 사건이 있습니다. 모든 사건을 한 생애에 보지는 않습니다. 지역 사건은 현재 지방, 후속 사건은 이전 결정으로 해금됩니다.
- **세계관 사건**: 로켓단·플라스마단·플레어단·스타단, 불탄탑, 천관산, 울트라홀, 에리어 제로, 섬의 시련, 배틀 서브웨이, 체육관 챌린지 등. 사건·대사는 팬 창작이며 원작 줄거리 재현을 주장하지 않습니다.
- **필드**: 방향키/WASD, 클릭, 모바일 방향 버튼으로 이동합니다. 연구소·센터·체육관의 입구에 도착하면 시설을 이용합니다. 6세부터 연간 행동력 6으로 야생 배틀·훈련·조사·캠프를 이용합니다. 다음 해에 행동력을 회복합니다.
- **파티**: 최대 6마리. 야생 배틀에서 HP를 낮추고 몬스터볼로 포획합니다. 연구소에서 지방당 스타팅 1마리를 분양받을 수 있습니다. 파티에서 선두를 바꿀 수 있습니다. 경험치·레벨·HP가 저장되며 스타팅 계열 등 지원 종은 레벨로 진화합니다. 기존 유대 기반 인생 진화도 유지합니다.
- **지방 이동**: 관동·성도·호연·신오·하나·칼로스·알로라·가라르·팔데아의 40개 마을. 이동은 300P와 행동력 1을 소모합니다. 출현 종·지역 사건·장비 해금이 지방마다 다릅니다.
- **배틀**: 턴제 공격·방어·포획·포기. 원작 타입 상성(무효, 이중 타입 포함), 자속 보정을 반영합니다. 9개 지방에서 각 8개 배지를 획득하며 관장 레벨이 상승합니다. 체육관 승리는 경험치와 상금을 지급합니다. 가라르 레이드는 거다이맥스 개체와 인자를 제공합니다.

## 특수 배틀 시스템

통합 팬 룰로 **한 배틀에 특수 시스템 하나**만 사용합니다. 원작의 세대별 공존 제한을 그대로 적용하지 않습니다.

| 시스템 | 해금·조건 | 적용 |
| --- | --- | --- |
| 메가진화 | 칼로스/호연 연구소, 배지 1개, 500P, 키스톤+대상 메가스톤 | 대응 46종, 실제 폼 이미지, 종료까지 공격 강화 |
| Z기술 | 알로라 연구소, 배지 1개, 500P, Z링+같은 타입 크리스탈 | 다음 기술을 한 번 강화 |
| 다이맥스 | 가라르 연구소, 배지 1개, 500P | 가라르 체육관/레이드에서 3턴 HP·위력 강화 |
| 거다이맥스 | 다이맥스 장비+레이드에서 얻은 해당 종 인자 | 대응 32종, 실제 폼 이미지, 3턴 강화 기술 |
| 테라스탈 | 팔데아 연구소, 배지 1개, 500P | 지정 테라타입으로 방어 상성 변경, 자속 보정; 센터에서 오브 충전 |

배틀 수치·기술 구성·메가스톤 묶음 지급·체육관 상대·기술별 부가 효과는 간소화한 게임 규칙입니다. 원작의 종족값/노력치/개체값/특성/전체 기술 목록과 모든 진화 조건은 아직 재현하지 않습니다. 전설의 포켓몬 관측은 자동 포획이 아닙니다.

관동·호연은 pret 기반 원작 지도, 나머지 지방은 **이동 노선도**를 표시합니다. 필드는 이 게임에서 만든 공통 배치를 사용하며 환경별 색상이 달라집니다. 전체 원작 도시 지형을 탐색하는 구현은 아닙니다.

## 저장

`localStorage`의 `pokelife.story.v1`에 자동 저장합니다. 기존 v1 기록은 수명·필드 상태를 추가해 마이그레이션하며 기존 기록과 선택을 유지합니다. 선택/만남 대기와 배틀 중 HP·변신·턴도 복원됩니다. 이미 끝난 예전 생애는 완료 상태를 유지합니다.

설정에서 JSON 내보내기/불러오기, 생애 종료 화면에서 TXT 기록 내려받기를 지원합니다. 데이터 교체 전 `.previous`, 손상된 저장은 `.recovery` 키에 보존합니다. 계정 및 클라우드 동기화는 없습니다.

## 코드와 검증

- `src/engine.js`: 생애, 결정, 수명, 저장 검증과 마이그레이션.
- `src/game.js`: 필드 행동, 경제, 레벨, 포획, 배틀과 특수 시스템.
- `src/data/{regions,quests,regional-stories}.js`: 지방과 분기 사건.
- `src/data/battle-data.js`: 로컬 PokéAPI CSV에서 추출한 타입/상성.
- `src/GameUI.jsx`, `src/game.css`: 게임 대시보드, 필드, 파티, 배틀, 이동 UI.
- `src/App.jsx`, `src/components.jsx`: 진행, 결정 팝업, 도감, 저장, 주요 만남 연출.
- `tests/`: 전체 생애·상태 불변식·변신·이동·저장 테스트 및 데스크톱/모바일 실제 UI 테스트.

## 자료 출처

[자료실](resources/README.md) · [출처 및 권리 구분](resources/SOURCES.md). 도감/상성: PokéAPI. 포켓몬 및 변신 스프라이트: PokeAPI/sprites. 트레이너 시트와 일부 지도: pret/pokefirered, pret/pokeemerald. 새 폼의 다운로드 URL·SHA-256은 `resources/catalog/game-expansion-assets.json`에 기록합니다.
