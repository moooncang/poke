# Pokélife

[플레이](https://moooncang.github.io/poke/) · 선택으로 진행하는 포켓몬 인생 시뮬레이션.

## 협업 작업 기록

- **Claude — 삶의 목표·파티 직접 관리·전 지방 리그·가문(다회차):** [변경·규칙·검증 기록](docs/CHANGES-legacy-league.md) · [디자인 인계](docs/DESIGN-HANDOFF.md). 커뮤니티 피드백을 반영해 모바일에서도 보이는 트레이너 HUD, 포켓몬 고정·직접 편성·선두 지정, 타이틀 수에 따라 강해지는 리그와 체육관 원정·본선 시즌 도전·다른 지방 원정, 엔딩 카드·트레이너 카드·메달·누적 도감·다음 세대에게 알 물려주기를 추가했습니다. 저장 형식 4로 자동 이전됩니다. 화면은 기능만 갖춘 상태이며 디자인은 GPT가 맡습니다.

- **Codex — 5단계 재능:** [배정·분기·저장 이전 기록](docs/CHANGES-talents.md). 4개 재능 분야와 5단계, 20개 전용 사건, 학습·진로 추가 선택 및 후속 숙련을 추가했습니다. 저장 형식 3으로 자동 이전됩니다.

- **Codex — 교배·모험 116개 사건:** [규칙·분량·검증 기록](docs/CHANGES-breeding-adventures.md). 실제 알그룹에 따른 교배, 알 돌봄·부화·세대 기록과 36개 모험의 108개 장면을 추가했습니다. 레드·난천·단델 초청전, N과의 여행, 첫 파트너의 귀향 등이 조건부로 이어집니다.

- **Codex — 포획 중복·엔딩:** [변경·검증 기록](docs/CHANGES-life-archive.md). 진화 계열과 박스까지 확인해 새 동료를 우선하며, 엔딩을 검색 가능한 생애 연표·동료 앨범·리그 업적 기록관으로 확장했습니다.

- **Codex — 직업·리그 장기 전개:** [변경·조건·검증 기록](docs/CHANGES-career-sagas.md). 직업 프로젝트 96개, 9개 지방 리그 사건 90개와 여파 3개를 추가했습니다. 지역 배지 8개·예선·4관문을 통과하면 챔피언 대표 팀 3연전에 도전하며, 우승은 명예의 전당·초청전·귀향·후배 이야기로 이어집니다.

- **Claude — 시뮬레이션 v2:** [구조·세계·인연·선택의 여파·자동 파티 변경 기록](docs/CHANGES-v2.md)
- **Codex — 2026-10-11 UI:** [청록색 대시보드 변경·파일 위치·검수 기록](docs/CHANGES-ui-console.md). 최신 Claude 병합분 위에서 트레이너/기록/파티의 3열 화면, 분홍색 라이선스·결정 헤더, 모바일 배치와 어두운 테마를 적용했습니다. 엔진과 저장 규칙은 유지했습니다.
- 다음 작업자는 [AGENTS.md](AGENTS.md)와 위 변경 기록을 먼저 확인하고, 작업 뒤 이 목록과 상세 기록을 갱신해 주세요.

## 현재 플레이 방식

- 출생 시 9개 지방·40개 마을 중 출생지, 가족 구성·형편·주거·주변 환경, 소꿉친구, 타고난 성향을 무작위 배정합니다. 성별은 남성·여성·미지정·무작위 중 고르며 능력치나 진로를 제한하지 않습니다.
- 삶은 자동 진행되며 사건이 나오면 팝업에서 결정합니다. 선택창 사이에는 기록 4~7개가 자동으로 쌓이고, 배속은 1·2·3·4·16배, 일시 정지와 자동 결정을 지원합니다. ‘잠깐 숨기고 화면 보기’로 선택을 보류한 채 기록·도감·지도를 둘러볼 수 있고, 하단에서 선택 후 배속을 바꿀 수 있습니다.
- **나이에 고정된 사건은 최소한만 남겼습니다.** 6세 첫 파트너, 7·12세 학습 방식, 10세 주요 인물, 16세 진로, 18·22세 진학·견습·취업 선택만 정해진 나이에 옵니다. 경력 평가(첫 경력 평가·전문 분야·직업 재설계·후배 육성·은퇴 준비)는 26·35·40·50·60세 단계마다 한 번씩, 삶마다 다른 나이(단계 시작 후 0~2년)에 옵니다. 그 밖의 사건(이주, 전직, 귀향, 은퇴, 입양, 전설 조사 등)은 세계와 인물의 상태, 성향, 소지금, 명성에 따라 그때그때 열립니다.
- **경력.** 경력 평가에서 승급·전직·현직 유지·자율 활동을 고릅니다. 경력 등급은 최대 5단계로 단계마다 연 수입이 15% 늘고, 아카데미 이력은 연구직 평가 난이도를 낮춥니다. 파티의 연간 기본 경험치는 트레이너 48·연구원 28·돌보미 36·상인 18·무직 20이며, 학업·견습·여행과 직전 활동에 보너스가 붙고 건강 35 미만이면 60%, 65세 이후에는 70%로 줄어듭니다.
- **변하는 세계.** 지방마다 경기·치안·생태 수치가 있고 해마다 스스로 변합니다. 경기 침체, 개발 호황, 악당 조직 활동, 이상 기후, 포켓몬 감기, 리그 개최, 신종 발견, 전설 목격, 풍작, 대이동 같은 상황이 무작위로 생겼다 사라지며 ‘지방 소식’으로 기록됩니다. 경기는 연 수입과 생활비를, 치안·생태는 찾아오는 사건과 야생 포켓몬을 바꿉니다. 플레이어의 선택도 지방 수치를 움직입니다.
- **스스로 사는 사람들.** 소꿉친구·라이벌·형제·고향 가족이 각자 진로를 정하고, 실직하고, 결혼하고, 아프고, 세상을 떠납니다. 라이벌은 관계와 치안에 따라 체육관 관장이 되기도 하고 조직에 들어가기도 합니다. 관계 수치에 따라 부탁·동업·선물·대결 사건이 생깁니다.
- **선택의 여파.** 선택은 몇 년 뒤의 결과를 남깁니다. 빌려준 돈, 동업 투자, 서식지 보호 운동, 무시한 라이벌, 실패한 시험 같은 선택이 2~12년 뒤 ‘지난 선택의 여파’ 기록이나 새 결정으로 돌아오고, 투자 결과는 만기 시점의 경기로 정해집니다. 선택마다 대담·탐구·배려·실리·여유 중 하나의 성향이 쌓이며, 성향은 자동 결정과 파티 구성 기준이 됩니다. 학습 방식은 바뀔 때까지 매년 해당 능력치를 올립니다. 능력치는 해마다 기준값으로 조금씩 돌아가므로 지금의 생활이 반영됩니다.
- **삶의 목표.** 흘러가는 대로·리그 제패·도감 완성·가족과 인연·일의 정점 중 고르면 해당 사건이 더 자주 오고 자동 결정도 그쪽으로 기웁니다. 언제든 바꿀 수 있습니다.
- **파티 직접 관리.** 상단 HUD의 파티 버튼에서 좋아하는 포켓몬을 고정하거나, 직접 편성 모드로 바꾸거나, 박스와 파티를 교체하고 선두를 정할 수 있습니다. 박스의 포켓몬도 연간 경험치의 25%를 받습니다.
- **전 지방 리그.** 리그 상대 레벨은 처음 도전할 때 최종 Lv.54이고 타이틀을 딸 때마다 6씩 오릅니다. 체육관 원정으로 배지를 한 번에 여러 개 얻고, 남은 본선을 한 시즌에 몰아서 도전하고, 제패 후 다른 지방 리그로 원정을 떠날 수 있습니다.
- **가문의 전당(다회차).** 끝낸 삶은 트레이너 카드·엔딩 카드·메달과 함께 전당에 걸리고 도감이 누적됩니다. 엔딩에서 고른 알은 다음 삶의 6세 첫 파트너로 부화하고 유산이 함께 전해집니다.
- **파티와 PC 박스.** 포켓몬이 6마리를 넘으면 캐릭터가 성향(대담하면 강한 포켓몬, 배려하면 정든 포켓몬, 탐구형이면 타입 다양성 등)과 직업에 맞춰 스스로 파티를 다시 짜고 나머지를 PC 박스에 맡깁니다. 해마다 박스와 파티를 다시 검토하며, 첫 파트너는 거의 언제나 남습니다. 포획·입양·알·친구의 선물·구조 등으로 포켓몬이 늘어납니다.
- **타고난 재능.** 배틀·탐구·교감·제작/경영 중 한 분야와 기초형·보통·유망주·수재·천재의 5단계를 배정합니다. 관련 도전 확률과 직업별 파티 육성 속도에 반영되며, 단계별 사건과 학습·진로 분기가 열립니다. 후속 연습으로 숙련을 얻거나 다른 진로를 선택할 수 있습니다.
- **교배와 알 돌봄.** 16세 이후 파티·박스에 교배 가능한 조합이 있으면 사건으로 제안됩니다. 알그룹과 개체 성별, 유대·친밀도·직업을 반영하며 돌봄→부화→성장 소식으로 이어집니다. 직접 키우거나 다른 트레이너에게 맡길 수 있습니다. 야생 포획과 달리 선택한 교배는 같은 계열의 새 개체를 얻을 수 있습니다.
- **전설의 포켓몬.** 전설과 마주치면 포획(용기 판정)·신뢰 쌓기(유대 판정)·관찰 중에서 고릅니다. 손에 넣은 전설의 포켓몬은 언제나 파티에 들어가며 박스로 보내지지 않습니다. 놓친 전설은 몇 년 뒤 다시 나타날 수 있습니다.
- 메인 사건은 모두 826종입니다. 인생 단계·성향·가족·포켓몬·직업·마을 환경·지방 문화·지방 상황별 사건이 조건에 맞을 때 열리고, 결정 사이에는 계절과 환경에 맞는 일상 기록이 쌓입니다.
- 스탯 판정 사건 60종과 아카데미 특별전형, 32개 장기 활동 경로, 27개 지방 사건 경로, 18단계 관계 사건을 유지했습니다. 동네 사건의 도전 2개와 장기 경로의 전문 평가·협업에도 성공/실패 판정이 있고, 확정 지원 보상은 20P·유대 1입니다. 성공률은 `25 + 스탯 × 0.7 - 난이도 + 해당 분야 재능·숙련 보정`를 5–95%로 제한하며 선택 전에 표시합니다. 판정에는 저장된 난수를 쓰므로 새로고침으로 결과가 바뀌지 않습니다.
- 야생 조우는 마지막 조우 후 3년이 지나면 우선 배정되고, 트레이너·연구원은 더 자주 만납니다. 배틀 포획·먹이 유인(유대 판정)·습성 분석(지혜 판정)·관찰 중에서 고르며, 몬스터볼은 매년 3개씩 보충됩니다(최대 30개).
- 배틀·포획은 사건 선택의 결과로 자동 진행됩니다. 캐릭터가 상성을 보고 선두를 고르고, 포획할 때는 기절시키지 않고 볼을 던집니다. 메가진화·Z기술·다이맥스·거다이맥스·테라스탈은 장비와 조건을 갖추면 자동으로 사용됩니다. 파티의 모든 포켓몬은 레벨(일부는 친밀도)에 따라 진화합니다.
- 수명은 개인별 64–100세 한계와 60세 이후 건강에 따른 조기 사망 확률로 결정하는 창작 규칙입니다.

## 코드 구조

함께 작업하는 에이전트와 사람을 위한 규칙은 [AGENTS.md](AGENTS.md), 최근 구조 변경 내역은 [docs/CHANGES-v2.md](docs/CHANGES-v2.md)에 있습니다.

- `src/engine.js`: 공개 API(`createLife`, `advance`, `choose`, `autoChoice` 등). 한 번의 `advance`는 기록 1개를 추가합니다.
- `src/sim/`: 시뮬레이션 모듈. `world.js`(지방 정세), `people.js`(인물), `party.js`(파티·박스·진화), `battle.js`(자동 배틀), `consequences.js`(지연 결과), `director.js`(사건 선택), `save.js`(검증·이전 저장 변환), `random.js`(결정적 난수).
- `src/data/`: 사건·인물·지방 데이터. `storylets.js`는 상태에 따라 열리는 사건, `consequences.js`는 선택의 여파, `species-rules.js`는 `scripts/build_species_rules.mjs`가 PokéAPI 자료에서 생성한 진화·전설 목록입니다.
- `src/ui/`: 화면 구성 요소.

## 개발·배포

```sh
npm ci
npm run dev
npm test
PAGES_BASE_PATH=/poke/ npm run build
```

Node 24 사용. `main` 푸시 시 GitHub Actions에서 테스트·빌드·Pages 배포를 실행합니다. 빌드 산출물 `pokelife-dist`는 Actions에서 내려받을 수 있습니다. 브라우저 테스트는 `npm run test:browser`이며 Chromium 경로를 `CHROMIUM_PATH`로 지정할 수 있습니다.

저장은 `localStorage`의 `pokelife.story.v1` 키에 저장 형식 4로 기록합니다. 끝낸 삶의 기록(가문의 전당)은 `pokelife.legacy.v1`에 따로 저장합니다. 형식 1·2·3 저장은 불러올 때 진행 중인 선택을 유지한 채 자동 변환합니다. 설정에서 JSON 내보내기/복원을 지원합니다. 계정 동기화는 없습니다. 새 삶으로 교체하기 전 `.previous`, 손상된 데이터는 `.recovery` 키에 보존합니다.
