# 포켓몬 인생 시뮬레이션 자료실

게임 제작을 위한 공개 자료 수집본. 원본 5,231개 파일을 내려받았으며, 파생 데이터와 PNG 지도는 별도로 생성했다. 외부 API 호출 없이 자료를 사용할 수 있다. 게임이나 인생 이벤트 본문을 구현한 상태는 아니다.

`catalog/summary.json`과 `catalog/validation.json`에 기계가 읽는 수량·검증 결과를 기록했다.

## 사용할 파일

- `catalog/pokemon.json`: 한국어 이름, 타입, 진화 계보·조건, 한·영 도감 설명, 이미지 경로. 도감 문장별 게임 버전 ID를 보존한다.
- `catalog/regions.json`, `catalog/locations.json`: 공식 게임에서 유래한 지방·장소 정보. 장소에는 도로·동굴·시설도 포함하므로 전체를 출생지로 사용하면 안 된다.
- `catalog/encounters-by-location.json`: 지역 이벤트에 등장할 포켓몬 후보. 여러 게임 버전을 합친 **종 목록**이며 출현 확률이 아니다. 버전별 확률·조건은 원본 `encounters.csv`, `encounter_slots.csv`, `encounter_condition_value_map.csv` 등을 함께 조회해야 한다.
- `catalog/maps.json`: 맵 유형, 이웃 연결, 날씨, NPC 수, 원본 경로. 도시·마을 필터는 `MAP_TYPE_TOWN`, `MAP_TYPE_CITY`. PokéAPI 장소 연결은 식별자가 정확히 일치할 때만 추가했다.
- `catalog/items.json`, `catalog/natures.json`: 생활 소재와 포켓몬 성격.
- `assets/pokemon/{front,shiny,artwork,back}/<전국도감번호>.png`: UI에 연결할 포켓몬 이미지.
- `assets/items/`: 확보된 아이템 아이콘.
- `assets/maps/`: 원본 타일·배치·팔레트를 해석해 만든 지방 지도 PNG. 호연은 원본 512×512 캔버스로 넓은 바다 여백이 포함된다.
- `raw/pokefirered/`, `raw/pokeemerald/`: 원작 맵 JSON, 지방 지도 타일, NPC 시트, 트레이너 이미지. **943개의 완성된 마을 스크린샷이 아니다.** 마을 전체를 렌더링하려면 추가로 레이아웃·메타타일 등을 수집해야 한다. NPC 시트 역시 프레임 분리·투명색 처리가 필요할 수 있다.
- `manifest.json`: 내려받은 파일마다 원본 URL, 고정 커밋, SHA-256, 크기와 누락 사유.
- `catalog/derived-maps.json`: 변환된 지도와 입력 파일 해시.

경로는 `resources/` 기준이다. 웹 배포 시 원본 CSV 전체를 번들에 넣기보다 필요한 catalog와 이미지부터 사용한다.

## 출처와 권리

자세한 원문 링크와 구분은 [SOURCES.md](SOURCES.md)에 있다. **공개 다운로드 가능과 포켓몬 원본 이미지·문구의 자유로운 재배포 허용은 같은 뜻이 아니다.** 라이선스 문구를 함께 보존했으며 모든 자료가 상업적 이용 가능한 오픈소스라고 표시하지 않는다.

## 재현

저장소 루트에서 Python 3으로 실행한다. 다운로드·목록 생성은 표준 라이브러리만 사용하고, 지도 변환·PNG 검증은 Pillow가 필요하다. 현재 환경의 Pillow 12.3.0으로 검증했다.

```sh
python scripts/fetch_resources.py
python scripts/build_resource_index.py
python scripts/decode_region_maps.py
python scripts/validate_resources.py
```

다운로드는 고정 커밋을 사용하며 이미 존재하는 이미지의 해시가 맞으면 재사용한다. 원본 압축 파일은 고정 SHA-256을 검사한다. 다른 환경에 Pillow가 없다면 별도 가상환경에 `Pillow==12.3.0`을 설치한다. 네트워크 목적지는 `codeload.github.com`, `raw.githubusercontent.com`이다.

## 현재 빈 부분

- 899–1,025번은 수집한 원본에 한국어 도감 설명이 없다. 영어 원문을 제공하며 번역문을 공식 한국어 문장으로 가장하지 않는다.
- 장소 818개와 지방 1개는 한국어 명칭이 없다. 영어 이름 또는 식별자로 표시하고 별도 확인·번역이 필요하다.
- 선택한 아이템 이미지 중 49개는 고정 원본 URL이 404다. catalog에서는 이미지 경로를 null로 두며 실제 목록은 manifest에 있다. 라이선스는 `LICENCE.txt`로 확보했고 `LICENSE`, `LICENSE.md`의 404는 대체 파일명 탐색 기록이다.
- PNG 지방 지도는 관동·호연·일곱섬을 확보했다. 다른 지방의 지도 이미지는 아직 수집하지 않았다.
- 자료량이 게임 플레이 분량을 뜻하지 않는다. 인생 사건·직업·가족·관계·기억과 후속 사건은 별도 창작해야 한다.

## 이 자료로 넓힐 콘텐츠

1. 도시·마을별 출생 배경과 연결 도로를 이용한 여행·이주.
2. 지역 출현 포켓몬과 첫 만남, 구조, 동행, 귀향 후 재회.
3. 종별 생태 설명을 바탕으로 돌봄·농사·연구·상점·해양 직업 사건.
4. 성격·진화 조건·나무열매·아이템을 연결한 파트너 성장 서사.
5. 같은 사건을 단순히 이름만 바꾸기보다 인물의 과거와 결과를 기억하는 연속 사건.

인구, 출생 확률, 직업 분포, 가족 설정, 인간 수명은 이 데이터의 공식 설정으로 취급하지 않는다. 히스이 같은 시대 차이도 시뮬레이션의 별도 설정이 필요하다.
